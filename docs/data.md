# Data Strategy

## Overview

This document describes the datasets EduPath needs, their sources, formats, and how they feed into the ML pipeline.

## Data Categories

### 1. Student Assessment Data
- **Description:** Responses from the Brain Power Assessment (aptitude scores, interest ratings, academic grades, goals)
- **Source:** EduPath platform (generated by users)
- **Format:** JSON / CSV
- **Privacy:** Anonymised; no PII stored
- **Location:** `data/raw/assessments/`

### 2. Career Knowledge Base
- **Description:** Structured mapping of careers → streams → exams → colleges → job roles → skills
- **Source:** Manually curated + web-scraped (NIRF, NIC, exam boards)
- **Format:** JSON
- **Location:** `data/processed/career_kb.json`

### 3. College Dataset
- **Description:** College name, location, type (govt/private), fees, NIRF rank, cutoffs, placements, NCC facility
- **Source:** NIRF rankings, official college websites, Shiksha / CollegeDunia scrape
- **Format:** CSV
- **Location:** `data/raw/colleges/`, `data/processed/colleges_clean.csv`

### 4. Entrance Exam Dataset
- **Description:** Exam name, conducting body, eligibility, syllabus summary, exam date pattern, seats available
- **Source:** Official exam websites, NTA, CLAT consortium
- **Format:** JSON / CSV
- **Location:** `data/raw/exams/`, `data/processed/exams_clean.json`

### 5. Job Roles & Skills Dataset
- **Description:** Job role name, career cluster, required skills, avg salary, growth outlook
- **Source:** LinkedIn job postings (scraped), NSDC reports, O*NET
- **Format:** CSV / JSON
- **Location:** `data/raw/jobs/`, `data/processed/jobs_clean.csv`

## Data Pipeline

```
raw/  →  cleaning & validation  →  processed/  →  ML models / API
```

### Steps
1. **Ingestion** — collect from sources (manual entry, scraping, APIs)
2. **Cleaning** — remove duplicates, handle missing values, normalise text
3. **Feature Engineering** — encode categorical variables, scale numeric features
4. **Validation** — schema checks, range validation, consistency tests
5. **Export** — ready-to-use CSV/JSON for ML training and API serving

## Licensing & Ethics

- All scraped data will comply with respective website terms of service
- Student assessment data will never be sold or shared with third parties
- Datasets will be versioned and documented before use in production
