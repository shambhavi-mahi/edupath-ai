# EduPath Assessment

## Purpose

Measure student aptitude, interests and academic profile to support personalized career exploration.

## Aptitude Dimensions

1. Logical Reasoning
2. Numerical Ability
3. Verbal Ability
4. Analytical Thinking
5. Problem Solving
6. Memory
7. Creativity
8. Attention
9. Spatial Reasoning

## Aptitude Questions

5 questions per dimension
Total = 45 questions
*(Currently operating under a Stage 1 Prototype with 27 questions: 3 per dimension).*

## Scoring

Correct answer = 1 point
Incorrect answer = 0 points

Dimension Score = (points obtained / maximum points) × 100

## Interest Assessment

15–20 questions

Scale:
1 = Not interested
2 = Slightly interested
3 = Neutral
4 = Interested
5 = Very interested

## Academic Data

- Current class/year
- Relevant subjects
- Subject scores
- Overall percentage/CGPA

## Output

- 9-dimensional profile
- Interest profile
- Academic profile
- Career matches
- Explanation
- Skill gaps
- Personalized roadmap
