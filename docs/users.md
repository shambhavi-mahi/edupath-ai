# Target Users

## Primary Users

High-school students, especially Classes 10–12.

## Secondary Users

Undergraduate students exploring career options,
specializations, internships and skill development.

## Primary User Problem

"I know I need to choose a direction, but I don't know
which options fit my strengths and interests."

## Parent Value

Parents can understand the student's strengths and
explore possible educational pathways.

## Student Value

Students receive personalized career exploration,
skill-gap analysis and a roadmap.
